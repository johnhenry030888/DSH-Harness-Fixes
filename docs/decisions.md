| 2026-09-25 | Bug 005: host-side live catalog overlay + startup refresh, and remove the `opencode-go` `models:` pin from `~/.dsh/settings.yaml` | A pin replaces the catalog and cannot express mixed wire protocols; bumping pi-ai (0.86.0 still ships 27) or editing its generated data is release-locked; pi-ai's `Models.refresh()` is unused by dsh and its snapshot lifecycle is rebuilt per config change. The overlay reuses pi-ai's tested descriptors and fails safe to the bundled catalog. |
| 2026-09-25 | Bug 005: the `models:` pin re-added before drill v3 was removed again (backup `~/.dsh/settings.yaml.bak-pre-bug010-20260925`) | A non-empty pin replaces the live catalog, so `check-all.sh` fails bug 005 while it is present. The drill's 8 expected routes are all in the live catalog (plus 24 more); restoring the backup intentionally re-freezes the list and reds the bug-005 gate. |
| 2026-09-25 | Bug 006: workflow `toolFilter` is deployment-owned engine config, passed to `subagents.start()`; never read from model-authored `meta`/script args | The engine owns worker lifecycle, so it owns the worker's capability mask; script-selectable masks would be fail-open. The delegation seam already supports `toolFilter` on every provider. |
| 2026-09-25 | Bug 007: tolerate unknown names in the child composition (drop + warn), keep `tools.restrict()` strict, and add row-identified pre-spawn/`agent/created` validation | Making `restrict()` tolerant weakens the typo guard for every caller; rows mount concurrently so a literal standing-mount registry check would false-fail valid presets that name a later row's tool. The tolerant branch prevents the outage, the validation names the offending row. |
| 2026-09-25 | Bug 008: warn + reword instead of changing the fork seed rule; do not extend the versioned `subagent/descriptor` | An unbalanced in-flight turn is not a valid child seed (module docstring), and bumping `SUBAGENT_DESCRIPTOR_VERSION` for a non-composition fact would make existing v3 children unreadable on cold resume. `Session.inheritedEventCount` already records the truth durably. |
| 2026-09-25 | Bug 009: classify route rejections via `llm.listModels` in the delegation tool; render the effort ladder in `dsh-llm` | The tool owns Session policy; the LLM layer owns model metadata. Consulting the catalog only on the failure path keeps the happy path unchanged. |
| 2026-09-25 | Bug 010: timestamp `list_agents` samples instead of inventing more states; surface the route from the agent loop via a new `AGENT_ROUTE` context slot | The live registry only exposes `idle`/`running`, so richer states would guess; the timestamp makes the existing vocabulary honest. The loop owns the agent's options and request header, so it owns the route line; the effort is reported as unresolved before the first request rather than guessed. |
